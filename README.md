## Install

| Platform | Download |
| --- | --- |
| macOS (Apple Silicon) | [Viktor.dmg](https://github.com/zetalabs-ai/viktor-desktop-releases/releases/download/desktop-v0.1.2724/Viktor_0.1.2724_aarch64.dmg) |
| Windows (x64) | [Viktor setup.exe](https://github.com/zetalabs-ai/viktor-desktop-releases/releases/download/desktop-v0.1.2724/Viktor_0.1.2724_x64-setup.exe) |
| Linux | [AppImage](https://github.com/zetalabs-ai/viktor-desktop-releases/releases/download/desktop-v0.1.2724/Viktor_0.1.2724_amd64.AppImage) · [deb](https://github.com/zetalabs-ai/viktor-desktop-releases/releases/download/desktop-v0.1.2724/Viktor_0.1.2724_amd64.deb) · [rpm](https://github.com/zetalabs-ai/viktor-desktop-releases/releases/download/desktop-v0.1.2724/Viktor-0.1.2724-1.x86_64.rpm) |

After installing, the app keeps itself up to date — macOS, Windows, and the Linux AppImage and deb self-update; rpm installs do not.

Notes:
- Windows builds are not code-signed yet: if SmartScreen warns, choose "More info" → "Run anyway".
- There is currently no Intel macOS build.
