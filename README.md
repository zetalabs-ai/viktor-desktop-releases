# Viktor Desktop — stable channel

## Install

| Platform | Download |
| --- | --- |
| macOS (Apple Silicon) | [Viktor.dmg](https://github.com/zetalabs-ai/viktor-desktop-releases/releases/download/desktop-v0.1.903/Viktor_0.1.903_aarch64.dmg) |
| Windows (x64) | [Viktor setup.exe](https://github.com/zetalabs-ai/viktor-desktop-releases/releases/download/desktop-v0.1.903/Viktor_0.1.903_x64-setup.exe) |
| Linux | [AppImage](https://github.com/zetalabs-ai/viktor-desktop-releases/releases/download/desktop-v0.1.903/Viktor_0.1.903_amd64.AppImage) · [deb](https://github.com/zetalabs-ai/viktor-desktop-releases/releases/download/desktop-v0.1.903/Viktor_0.1.903_amd64.deb) · [rpm](https://github.com/zetalabs-ai/viktor-desktop-releases/releases/download/desktop-v0.1.903/Viktor-0.1.903-1.x86_64.rpm) |

After installing, the app keeps itself up to date — macOS, Windows, and the Linux AppImage self-update; deb/rpm installs do not.

Notes:
- Windows builds are not code-signed yet: if SmartScreen warns, choose "More info" → "Run anyway".
- There is currently no Intel macOS build.
